目標ボード セットアップ（1回だけ・3分）

目標数値（OKRのKR3）は公開ページに直書きせず、ログインした人だけが読めるデータベースに入れます。

STEP 1

Supabase SQL Editor を開いて、下のSQLを貼り付けて RUN を押す

STEP 2

目標ボードを開く。クローザーボードにログイン済みのブラウザなら、そのまま表示されます（同じログインを共用）。

未ログインの場合はメールアドレスを入れてログインリンクを受け取ってください。もしリンクを開いてもログインできない場合は、Supabaseの Authentication → URL Configuration → Redirect URLs に https://kumiko0814.github.io/merone-goal-board/ を追加してください。

メモ

・月の合計は自動計算です（9月77件・10月100件・11月90件、Q合計COM267/CHA350）

・目標を変えたいときはSTEP1のSQLの数字を変えてもう一度RUNすれば上書きされます

・成約の実績は毎時、セールス個人成果シートから自動で入ります。チャネル別の実績は面談報告（クローザーボード）から数えています
